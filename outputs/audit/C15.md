### L35018 | 第18章3题 | 服务健康检查与优雅上下线
- 类型：1 事实错误
- 严重度：P1
- 原文：「public int getPhase() { return Integer.MIN_VALUE; }」
- 问题：SmartLifecycle 停止时按 phase **降序**执行，MIN_VALUE 会让该 stop() 最后执行——Web 容器已关闭后才去注销 Nacos，优雅停机逻辑实际失效。
- 建议：改为 `Integer.MAX_VALUE`（最先执行 stop），或用 `@PreDestroy` + `server.shutdown=graceful` 组合。
